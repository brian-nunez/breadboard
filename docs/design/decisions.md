# Decisions

Decisions that are costly to reverse have a full record in [`docs/adr/`](../adr/README.md); the rows below marked → ADR-NNNN link to it. New decisions of that kind get an ADR first and a row here; smaller decisions are recorded here only.

Brian owns material decisions: system boundaries, data models and file formats, public contracts (CLI, spec, env contracts), security policy, and direct dependencies. Record each new decision here when it is made; move an open question into the log once Brian resolves it. A superseded decision stays in the log, marked with what replaced it.

| D-046 | 2026-11-15 | The shared Go cache volumes mount with `volume.nocopy`, so Docker never copies the image's module cache into them. Apps start together, and concurrent copies into one new volume failed with `mkdir ...: file exists`. Go fills the caches itself on first start. |
| D-047 | 2026-11-15 | Starter app names are unique across all starters. Applying a starter whose app name is already used, other than by the same starter in the same directory, fails with `ErrExists` before anything is written, instead of skipping the app. |

| D-049 | 2026-11-15 | Starters may use any popular official SDK for the service they teach without a separate approval; each pin is listed in `starters.md`. `bb`'s own dependencies still need approval (ADR-0011). (Brian's direction.) |
| D-050 | 2026-11-15 | Apps default to `2g` of memory instead of `512m`. `go run` compiles dependencies inside the app container under its limit, and compiling `go-redis` v9 needs more than 1 GiB (measured: fails at 1g, succeeds at 1536m), so at 512m the compiler was killed and the app never started while still looking healthy. Supersedes the memory default in D-035. |
| D-051 | 2026-11-15 | `s3-compatible` runs `chrislusf/seaweedfs:4.53`. Only the S3 gateway listens on the network (HTTPS, 8333); internal servers bind to loopback; every gRPC port requires mutual TLS restricted to the service's own certificate; no plaintext listener. Completes the checks ADR-0010 deferred to Phase 2. → [ADR-0010](../adr/README.md) |
| D-052 | 2026-11-15 | `bb up` syncs `.bb/runtime/` instead of deleting and rewriting it: files with unchanged content and mode are left in place, changed files are rewritten, stale files are removed. Containers bind-mount single files from it, and a replaced file vanished inside containers compose did not recreate (seen on Docker Desktop). Changed files already change the service's config hash (D-040), so their containers are recreated. |
| D-053 | 2026-11-15 | Apps register with Consul through a Breadboard-managed sidecar, declared with `register` (`port`, optional `name` and `check`) in `experiment.yaml`. Recommended over self-registration, which is kept as a labeled alternative starter. (Brian's direction: both, sidecar advertised.) |
| D-054 | 2026-11-15 | Every app gets `BB_FQDN`, its own address (the name on its certificate), and the Consul server runs TLS health checks against the lab CA (`enable_agent_tls_for_checks`), so an app that registers itself can advertise a verifiable address. |
| D-055 | 2026-11-15 | `consul/self-registration` ships as a clearly labeled alternative to `consul/service-discovery`: its title says "alternative", its summary and README name the sidecar starter as recommended. | D-056 | 2026-11-16 | Starter apps are compiled in the image's `dev` stage (`go build -o /usr/local/bin/ ./cmd/...` with a BuildKit build-cache mount) and each app's `command` is its binary. | D-057 | 2026-11-16 | Bundles have one compose file: `docker-compose.dev.yml` (source mount and Go cache volumes) is no longer generated, since apps run binaries compiled into their images.
